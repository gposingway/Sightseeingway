# Sightseeingway Embedded Metadata — Schema v1

**Status:** Locked. Tolerant-reader contract.

## Contract

- Schema discriminator: `"schema": "sightseeingway/v1"` at the document root. The
  prefix before `/` identifies the producer; the suffix is the schema version.
- All fields are **optional**. A reader encountering a missing field must treat
  it as "unknown" and continue. A reader encountering an unknown field must
  ignore it, not reject the document.
- v1 will only ever gain new optional fields, never alter or remove existing
  ones. Any semantically-incompatible change requires a parallel v2 spec.
- Producer namespacing already happens at the file format level (PNG `iTXt`
  keyword, JPEG XMP namespace), so the JSON does not repeat it.

## Field reference

| Path | Type | Notes |
|---|---|---|
| `schema` | string | Always `"sightseeingway/v1"` for this spec. |
| `correlationId` | string (GUID v7) | Identifier shared with plugin diagnostic logs. RFC 9562. |
| `timestamp` | string (ISO 8601, UTC) | Captured close to the actual screenshot moment. |
| `character.name` | string | Localized character name. |
| `character.world.current` | string | Server the character is currently on. |
| `character.world.home` | string | Server the character is registered to. May differ when world-visiting. |
| `character.race` | `{id, name}` | `id` from FFXIV `Race` sheet; `name` localized. |
| `character.tribe` | `{id, name}` | `id` from FFXIV `Tribe` sheet; `name` localized. |
| `character.sex` | string | Normalized lowercase: `"male"` or `"female"`. |
| `character.job` | `{id, name, level}` | Active class/job. |
| `character.title` | string | Currently displayed title text, localized. |
| `character.grandCompany` | `{id, name, rank}` | Current GC affiliation + rank. |
| `character.mount` | `{id, name}` | Currently summoned mount, if any. |
| `character.minion` | `{id, name}` | Currently summoned minion, if any. |
| `freeCompany` | `{name, tag}` | FC affiliation; `tag` is the 5-char abbreviation. |
| `location.territory` | `{id, name}` | Zone-level identifier. |
| `location.map` | `{id, name}` | Sub-map identifier (housing wards, instanced areas). |
| `location.position` | `{x, y, z}` | Map-space coordinates. `z` may be 0 in flat zones. |
| `location.area` | `{id, name}` | Mid-tier breadcrumb below the zone (e.g. "Summerford"), from the live `TerritoryInfo`. Omitted when not standing in a named area. |
| `location.subArea` | `{id, name}` | Finest breadcrumb / landmark (e.g. "Summerford Farms"), from the live `TerritoryInfo`. Omitted when not standing in a named landmark. |
| `time.eorzea` | `{period, hour}` | `period` ∈ {Morning, Noon, Afternoon, Evening, Night, Midnight, Golden Hour}; `hour` 0-23. |
| `weather` | `{id, name}` | `id` from FFXIV `Weather` sheet. |
| `shader` | `{collection, preset, path}` | Active Shadingway preset, if Shadingway is detected. `path` is the full filesystem path to the preset's `.ini` (privacy: includes the user's install location; controlled by the same opt-in as the preset name). |
| `display` | `{width, height, aspectRatio, screenType}` | Screen capture dimensions and category, sourced from Shadingway's display section. `screenType` is a coarse classification ("4k", "1080p", etc.). |
| `flags` | string[] | See Flag vocabulary. |

### Flag vocabulary (v1)

Mode flags (in practice mutually exclusive, but enforce via consumer logic):

- `gpose` — group pose mode active
- `gameplay` — normal play (no special mode)
- `cutscene` — story cutscene playing
- `idle` — idle/AFK timer engaged

Context flags (orthogonal):

- `pvp` — in PvP zone or instance
- `housing` — inside a house/apartment
- `instance` — in instanced content (raid/dungeon/trial)

State flags (orthogonal):

- `mounted`, `swimming`, `flying`

## Format placement

| Format | Location | Identifier |
|---|---|---|
| PNG | `iTXt` chunk | Keyword: `Sightseeingway` |
| JPEG | XMP packet | Namespace: `https://gposingway.github.io/Sightseeingway/schema/v1` |

On re-injection, the writer must replace any existing chunk with the same
keyword/namespace, not append.
