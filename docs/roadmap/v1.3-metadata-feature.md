# v1.3 Metadata Feature — Implementation Roadmap

**Status:** Locked. Specs above are dependencies of this work.

## Sequencing

Four tracks. A and B+C run in parallel after A is mergeable. D is the release
wrapper.

### Track A — Foundation (no user-visible change yet)

**Goal:** prove snapshot + sidecar pipeline with no image bytes touched.

- [ ] `StateSnapshot` immutable record (full v1 schema surface).
- [ ] `CaptureState()` framework-tick-only function. Pure read of game state.
- [ ] Pattern B dispatch: on `FSW.Created`, post snapshot request to framework
      tick *before* file-release wait.
- [ ] Sidecar serializer (Newtonsoft.Json — existing dep).
- [ ] Rebuild rename pipeline as sidecar-driven task: write sidecar at original
      → rename `.png` → rename sidecar.
- [ ] Crash-recovery scan on startup. Process orphans per the table in the
      architecture doc.
- [ ] 60-second orphan grace period.
- [ ] File-release wait at injection point (helper extension; not yet called).
- [ ] Pipeline log file infrastructure (writer, daily rotation, ring buffer
      for diagnostics panel).
- [ ] Correlation ID generation + propagation through all the above.
- [ ] Round-trip tests for sidecar serialization + state machine transitions
      (pure logic, no Dalamud needed).

**Ships as:** 1.3.0-alpha.1, internal-only release for snapshot timing and
crash recovery validation.

### Track B — Metadata Writers

- [ ] `IMetadataWriter` interface.
- [ ] `PngMetadataWriter` — hand-rolled iTXt insertion, idempotent keyword
      replacement, atomic `.tmp` rename.
- [ ] `JpegMetadataWriter` — XMP packet write/replace, atomic `.tmp` rename.
- [ ] Format dispatcher (extension → writer).
- [ ] Background worker thread (named, IsBackground, no priority hint,
      ManualResetEventSlim signal with 30s timeout fallback).
- [ ] Shutdown contract: signal cancel, 5s grace, abandon.
- [ ] Hook injection step into the existing sidecar lifecycle from Track A.
- [ ] Fixture-based tests for both writers (round-trip, idempotent replace,
      malformed input rejection).

**Ships as:** 1.3.0-beta.1, brave testers opt in via the master toggle in the
v1.2 UI.

### Track C — UI Overhaul (parallelizable with B)

- [ ] Resize default window to 880×640.
- [ ] Two-column layout: Filename block (existing) | Metadata block (new).
- [ ] Master toggle + dimming behavior.
- [ ] Tri-state parent checkbox helper component.
- [ ] Three field groups (Scene, Character, Affiliation) with default
      selections per the UI doc.
- [ ] Collapsible group headers.
- [ ] `MetadataPreviewComponent` (live JSON preview).
- [ ] Diagnostics section: verbosity segmented control, pipeline status,
      recent events, action buttons.
- [ ] Save state visualization: amber tint, disabled state, asterisk in window
      title.
- [ ] Configuration migration v4 → v5.

### Track D — Release

- [ ] Bump `<Version>` to `1.3.0.0`.
- [ ] README section + link to `docs/schema/v1.md`.
- [ ] Plogon manifest update on a fresh `sightseeingway-1.3.0.0` branch
      (stable + testing/live).
- [ ] Changelog entry.

## Open dependencies resolved by these specs

- PNG manipulation: hand-rolled.
- JPEG support: in v1, via XMP.
- Character.Name default: ON (grandfathered).
- Character.World default: OFF.
- Worker thread: dedicated `Thread`, no priority hint, structural
  single-threadedness as throttle.
- Schema versioning: tolerant-reader, additive-only, `sightseeingway/v1`
  discriminator.
- Backfill: explicitly out of scope (forward-only feature).
- Schema namespacing: at the file format level (PNG iTXt keyword, JPEG XMP
  namespace), not in the JSON.
- Privacy classification: policy in plugin config, not in schema.
